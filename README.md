# Marketing Campaign Performance Analytics

## Project Overview

This project analyzes marketing campaign performance to understand which campaigns generated the highest customer engagement and return on investment. The goal was to identify patterns in campaign effectiveness and provide recommendations for improving future marketing decisions.

## Business Problem

Marketing teams invest significant budgets in campaigns across different channels. However, not every campaign produces the same results. This analysis aims to answer:

* Which campaigns performed best?
* Which channels generated the highest engagement?
* How efficiently was the marketing budget used?
* What factors influenced campaign success?

## Key Insights

* Some campaigns generated significantly higher engagement despite similar budgets.
* Certain marketing channels consistently outperformed others.
* Higher spending did not always result in better outcomes.
* ROI varied considerably across campaign types.
